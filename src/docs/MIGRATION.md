# 从懒人妈宝 6.0 迁移到二游辅助

## 已确认的旧版结构

旧安装包是 Python 3.12 / PyInstaller / PyQt5 应用，包含浏览器、书签、历史、
字幕方向解析、方向与转弯提醒、全局热键、自动对话和 ONNX 图像定位。

旧源码仓库尚未找到。当前只能从安装产物确认模块边界，不能把反编译结果当成
长期源码事实。

## 永久移除

- 卡密输入、设备解绑、登录心跳和剩余时长。
- 计费入口、购买链接和付费公告。
- 明文 HTTP 授权服务及客户端内嵌加密密钥。
- 旧 `update.exe` 覆盖式更新流程。
- 常规启动时的管理员提权。
- 应用自带广告、推广活动和启动时自动打开的推广网站。
- 黑色粒子动画及其持续重绘计时器。

## 已迁移功能

1. 攻略浏览：系统 Edge WebView2、地址栏、前进后退、刷新、收藏、历史和视频控制；
   启动页为本地 HTML，常见广告请求由 interceptor 拦截。
2. 方向提醒：事件式网页字幕、旧版方位词汇、8 方向与左右转解析、穿透浮窗、
   3 秒转向浮窗、自适应字幕浮窗和 2 秒区域投射增强提醒。
3. 自动对话：原神/星铁窗口配置、四张模板、多分辨率自检、按分辨率校准存储、
   后台识别、连续帧确认和用户显式解锁的真实输入。
4. AI 定位：旧 ONNX 方向模型和 XFeat 模型的 CPU 推理、0.82 余弦匹配、
   Homography/四角几何校验、共享 CLAHE、持续选区识别和方向浮窗联动。
5. 操作体验：8 项全局热键、视频跳转秒数、预设、主题、置顶、透明度、沉浸挖孔、
   智能避让和防遮挡。

真实自动按键仍受项目安全门约束：只有多分辨率/DPI 截图回归和用户实机确认通过后，
才能把 UI 中的“允许真实按键”从锁定状态释放。

## 首阶段验收

- `python -m eryou_assistant` 无登录直接进入主窗口。
- 运行时源码不存在旧卡密、计费和心跳标记。
- 默认进程不请求管理员权限。
- 五个功能入口均有可执行页面，不再使用迁移占位页。
- 主界面启动不发起远程请求，不加载推广开屏，背景不包含粒子动画。
- ruff、pytest 和离屏 Qt smoke test 通过。
- PyInstaller one-dir 包可安装到当前用户目录，且不触碰旧版安装路径。
