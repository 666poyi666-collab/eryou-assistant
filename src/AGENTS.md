# 二游辅助开发规则

- 产品必须保持纯免费、开源，不得引入卡密、订阅、计费、登录心跳或付费解锁。
- 应用显示名称统一为“二游辅助”，包名使用 `eryou_assistant`。
- 常规运行不得请求管理员权限；用户数据写入用户目录，不写 `Program Files`。
- 默认安装不捆 CUDA；AI 能力必须通过可选依赖提供。
- 自动操作必须默认安全，未完成识别回归前只能使用 dry-run。
- 不得修改 `C:\Program Files (x86)\LanRenMaBao` 旧安装目录。
- 每次变更至少通过 `ruff check .` 和 `pytest`。
